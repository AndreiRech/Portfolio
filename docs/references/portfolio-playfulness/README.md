# Referência visual

[OhnyFans](https://ohnyfans.com), capturado em 11/11/2026 com navegador real, em 1440 × 1000 e 390 × 844. Foram inspecionados o Hero, o café que reage ao clique, hover e respostas dos controles.

A direção preserva o carvão/coral e as fontes existentes do portfólio. Da referência vêm a composição assimétrica, a presença de uma peça interativa grande e as respostas táteis. No portfólio, essa peça é uma prévia de projeto real; o visitante pode selecionar outro trabalho. O passeio e as reações dos companheiros, o jogo e os detalhes de hover complementam a navegação profissional.

As capturas são material de referência; nenhuma arte, marca ou copy do site foi copiada para o produto. Os logos dos projetos já pertenciam ao repositório. Suas cópias `logo-thumb.webp` foram redimensionadas deterministicamente para 160 px com Sharp, qualidade 88, preservando os PNGs originais e a transparência. Nenhuma imagem foi gerada para este redesign.
